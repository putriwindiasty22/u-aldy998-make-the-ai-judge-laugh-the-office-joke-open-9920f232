One original one-line office joke for make.fun's "Make the AI Judge Laugh: The Office Joke (Open)" bounty. The program writes a single funny line about office life — automating your job only to end up in meetings about the automation — to `/output/entry.txt` (or `./output/entry.txt` when run locally). No dependencies, no network, Node 22.

## Run it

```sh
node main.ts
```

## The joke

> I automated my job with a script, so now I spend all day in meetings explaining to my boss why the script needs a meeting.

The program writes exactly that one line (122 characters) to `output/entry.txt`.
